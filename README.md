# College Placement Intelligence & Prediction System

## Project Overview

The College Placement Intelligence & Prediction System is a Business Intelligence and Predictive Analytics project developed to analyze college placement data.

The project uses historical student placement data to:

- Analyze placement outcomes
- Calculate important placement KPIs
- Explore academic and demographic factors associated with placement
- Analyze salary patterns
- Predict placement probability using Logistic Regression
- Categorize predicted placement risk
- Generate business-oriented insights and recommendations

---

## Dataset

**Dataset:** Placement_Data_Full_Class.csv

The dataset contains information about student academic performance, educational background, work experience, MBA specialization, placement status, and salary.

**Dataset source:** Kaggle

**Dataset file:** `data/Placement_Data_Full_Class.csv`

### Dataset Size

- Rows: 215 students
- Original columns: 15
- Target variable: Placement Status

The project analyzes variables including:
